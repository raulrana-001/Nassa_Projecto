# TerraWatch Angola — Frontend
HTML5 + CSS3 + JavaScript puro, Leaflet e Chart.js (sem frameworks).

    cd frontend
    python -m http.server 5500     # abrir http://localhost:5500

Sem backend, a interface usa dados DEMO (marcados). Com o FastAPI em http://localhost:8000/api passa a usar os endpoints reais (`API_BASE` em JS/api.js).
